# PC Analyzer — детальний опис

## Що робить програма

**PC Analyzer** — це веб-застосунок на Java (Spring Boot), який автоматично збирає оптимальні конфігурації ПК, аналізуючи ціни з українського маркетплейсу **[Hotline](https://hotline.ua)** та продуктивність компонентів з бенчмарк-сайту **[UserBenchmark](https://userbenchmark.com)**. Програма оцінює продуктивність процесора (ігровий, десктопний та робочий бенчмарки) і відеокарти (середній бенчмарк), допомагаючи вирахувати вартість у гривнях за одиницю продуктивності (₴/FPS). Зібрані конфігурації автоматично сортуються та фільтруються за продуктивністю та вартістю з урахуванням актуальних цін і фактично наявних у продажу комплектуючих, що дозволяє зробити аналітичний аналіз співвідношення потужності та вартості. Результат — Excel-звіт із готовими збірками, відсортованими за ціною за кадр (₴/FPS).

## Джерела даних

### 1. [Hotline](https://hotline.ua) (hotline.ua) — ціни в Україні

Програма парсить шість категорій комплектуючих за допомогою бібліотеки **Jsoup** (багатопотоково, з повторними спробами при помилках):

| Категорія | Що саме збирає |
|-----------|----------------|
| **Процесор (CPU)** | Виробник, модель, URL, ціни, середня ціна, сокет, частота, кеш L3, кількість ядер/потоків, тип пакування (Tray/Box/MPK), кількість пропозицій |
| **Відеокарта (GPU)** | Назва, URL, виробник, тип пам'яті (GDDR), об'єм пам'яті, шина, порт (PCIe), ціни, середня ціна, кількість пропозицій |
| **Материнська плата** | Назва, URL, виробник, сокет, чіпсет, виробник чіпсета, тип пам'яті (DDR4/DDR5), формфактор (ATX/ITX), ціни, середня ціна, кількість пропозицій |
| **Оперативна пам'ять** | Назва, URL, виробник, тип (DDR), об'єм, частота (МГц), ціни, середня ціна, кількість пропозицій |
| **SSD** | Назва, URL, виробник, тип, об'єм, швидкість читання/запису, ціни, середня ціна, кількість пропозицій |
| **Блок живлення (PSU)** | Назва, URL, виробник, тип (ATX), потужність (Вт), стандарт, підключення материнської плати/GPU, ціни, середня ціна, кількість пропозицій |

**Ціна:** парситься рядок на кшталт "12 345 грн – 15 678 грн", з якого береться середнє: `avgPrice = Math.min((min+max)/2, min*1.15)` — консервативна оцінка.

### 2. [UserBenchmark](https://userbenchmark.com) (userbenchmark.com) — продуктивність

Парсинг відбувається через **Selenium WebDriver** (Chrome), оскільки сайт має захист від ботів. Після завантаження сторінки HTML аналізується через Jsoup.

**Процесори (CPU):**
- Парситься таблиця з `cpu.userbenchmark.com` (посторінково)
- Для кожного процесора збирається: модель, виробник, рейтинг, середній бенчмарк, ціна, URL
- Додатково програма заходить на **сторінку кожного CPU** окремо, щоб отримати:
  - **gamingScore** — ігрова продуктивність
  - **desktopScore** — десктопна продуктивність
  - **workstationScore** — робоча станція
  - **coresQuantity** — кількість ядер
  - **threadsQuantity** — кількість потоків
- Для парсингу детальної сторінки використовується 3 різних CSS-шаблони (підстраховка, якщо сайт змінює верстку)

**Відеокарти (GPU):**
- Парситься таблиця з `gpu.userbenchmark.com`
- Збирається: модель, виробник, рейтинг, середній бенчмарк, ціна, URL
- **PowerRequirement** (енергоспоживання) вводиться вручну через веб-інтерфейс для нових відеокарт

**Нормалізація назв:**
Щоб зіставити моделі з [Hotline](https://hotline.ua) та [UserBenchmark](https://userbenchmark.com), назви приводяться до спільного вигляду:
- `"RTX 4070-Ti"` → `"RTX 4070 Ti"` (дефіс замінюється на пробіл)
- `"Core i7-13700KF"` → `"Core i7-13700K"` (спеціальні правила для серій)

## Як це поєднується

Після завантаження даних з обох джерел програма синхронізує їх:

1. **CPU:** для кожного процесора з [Hotline](https://hotline.ua) перевіряється, чи містить його назва назву процесора з [UserBenchmark](https://userbenchmark.com). Зіставлення відбувається від найдовшої моделі до найкоротшої, щоб уникнути помилкових збігів.
2. **GPU:** аналогічний механізм для відеокарт.

Якщо зіставлення успішне — до ціни з [Hotline](https://hotline.ua) додаються бенчмарк-показники з [UserBenchmark](https://userbenchmark.com).

## Як збираються конфігурації ПК

Програма створює всі можливі комбінації сумісних компонентів:

1. **Фільтрація:** відбираються компоненти, які мають >5 пропозицій на [Hotline](https://hotline.ua) (ознака доступності) та мають зіставлені бенчмарк-дані.

2. **Сумісність:**
   - **CPU + Материнська плата:** збіг за сокетом + логіка вибору чіпсета:
     - Intel K-серія → Z-чіпсет
     - AMD X-серія → X-чіпсет
     - Intel i5/i7/i9 або AMD Ryzen 5/7/9 (не K/X) → B-чіпсет
     - Інші — будь-який чіпсет
   - **Материнська плата + RAM:** збіг за типом пам'яті (DDR4/DDR5)
   - **GPU + Блок живлення:** найдешевший блок живлення, чия потужність ≥ енергоспоживання відеокарти

3. **Розрахунки для кожної збірки:**
   - **Загальна ціна** = CPU + охолодження (якщо Tray/Box без кулера) + корпус + материнська плата + RAM + GPU + SSD + блок живлення
   - **Прогноз FPS (Full HD):** `predictionGpuFpsFhd = gamingScore * avgGpuBench / 100`
   - **Ціна за кадр:** `priceForFps = totalPrice / predictionGpuFpsFhd`

4. **Відсів неконкурентних збірок:**
   Якщо збірка з нижчим FPS коштує дорожче за збірку з вищим FPS — вона видаляється.

5. **Маркування:** найкращі за ціною збірки отримують позначку `BEST_PRICE`.

## Аналітичні можливості Excel-звіту

Сформований Excel-файл дозволяє проводити такі види аналізу:

- **Порівняння ефективності збірок** — сортування за ціною за кадр (₴/FPS) показує, яка конфігурація дає найбільше кадрів за найменші гроші.
- **Аналіз продуктивності компонентів** — окремі колонки з ігровим бенчмарком CPU та середнім бенчмарком GPU дають змогу оцінити внесок кожного компонента в загальну продуктивність.
- **Бюджетне планування** — фільтрація за ціною дозволяє підібрати збірку під заданий бюджет (наприклад, до 30 000 ₴).
- **Виявлення «вузьких місць»** — аналізуючи співвідношення Gaming Score CPU та Avg Bench GPU, можна визначити, чи буде процесор «вузьким місцем» для відеокарти чи навпаки.
- **Кастомне сортування та фільтрація** — завдяки вбудованому автофільтру Excel можна відфільтрувати збірки за будь-якою колонкою: лише з певним процесором, відеокартою, діапазоном ціни або FPS.
- **Маркування найкращих пропозицій** — позначка `BEST_PRICE` візуально виділяє збірки з оптимальним співвідношенням ціни та продуктивності.

## Технології

- **Java 17** + **Spring Boot 3.4.1** (MVC, Data JPA, WebSocket, Thymeleaf)
- **MySQL** (через Docker + Flyway для міграцій)
- **Jsoup** — парсинг HTML [Hotline](https://hotline.ua)
- **Selenium** — парсинг [UserBenchmark](https://userbenchmark.com) (з обходом захисту)
- **Apache POI** — генерування Excel
- **MapStruct** — маппінг DTO та Entity
